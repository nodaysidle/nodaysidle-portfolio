# NODAYSIDLE portfolio

Cinematic portfolio of NODAYSIDLE apps with real GitHub Release downloads.

Cream / sage / lime (Landon-energy, not a clone). Living hero (rotating frames + lock + release ticker), film-chapter worlds (Capture / Create / Clean / Listen), Hall collectibles with GitHub release downloads. Display: Syne. Body: Plus Jakarta Sans. Quotes: Instrument Serif. Respects `prefers-reduced-motion`.

## Scripts

```bash
npm install
npm run dev      # local Vite server
npm run build   # production → dist/
npm run preview # serve dist/
```

## Stack

- Vite 8
- React 19
- `@vitejs/plugin-react`
